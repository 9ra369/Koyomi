# Koyomi

プロジェクトごとの労働時間を記録・管理するタイムトラッカー。

## 特徴（構想）

- プロジェクトごとに労働時間を記録
- タイマーでプロジェクトの稼働時間を計測
- 複数プロジェクトを管理可能
- データはローカルに保存
- Electron によるデスクトップアプリ化

## 現在の状態

[demo.html](demo.html) に、機能検証用の単一 HTML デモを実装済み。
ブラウザで直接開くだけで動作し、`localStorage` にデータを保存する。

```bash
# ブラウザで直接開く
start demo.html
```

Electron 版の実装はこれから進める。
